The brand CTA button — square corners, 12.5px uppercase Inter 600 tracked 0.14em; primary is ink-filled, secondary is outlined.

```jsx
<Button arrow>Book an Appointment</Button>
<Button variant="secondary">WhatsApp</Button>
```

`arrow` appends the ArrowUpRight glyph used on nearly every CTA. Hover: primary → stone; secondary → mist. Press: scale(0.98). Pass `href` to render an `<a>`.
